# Project context

This is the personal GitHub Pages site for btripple. It is a single-person repo, and the project is used as a site for HTML content only.

- GitHub repository: https://github.com/btripple/btripple.github.io
- Public URL: https://btripple.github.io/
- Default branch: `main`. GitHub Pages serves the site from this repo.

Changes pushed to `main` go live automatically on the public URL above. Because this is a single-person repo, commit and push to `main` directly when asked, without a branch or PR.
